The GPS's excuse, in its own voice, written for the make.fun bounty
"The GPS Swears It Was a Shortcut". It was not a wrong turn. It was a
scenic audit of your life choices, conducted at forty kilometres an
hour, and the cornfield you are parked in scored surprisingly high.

## Running it

`node main.ts` clears the output directory's contents and writes the
excuse to `/output/entry.txt` as plain UTF-8 text.
